02 · Working with AI

Give AI the context a teammate would need

Vague prompt

fix my code pls

AI has to guess the language, the error, and what “fixed” means.

Likely result: generic guesses

Clear prompt

Context

“I’m building a Flask login API for a class project.”

Problem

“POST /login returns error 500 when the password is empty. My code and the error are below.”

Task

“Explain the cause first, then suggest a minimal fix.”

Limits

“Keep the function signature. Don’t add new libraries.”

Likely result: a focused answer you can check

(~3 min) Compare the two prompts. The vague one forces the AI to guess. The clear one gives four things a human teammate would also need: Context: what you’re building. Problem: what happens, with the code and the exact error. Task: what you want back, and in what order. Limits: what must not change. Two extra tips. First, ask the AI to ask you questions: “What else do you need to know before answering?” Second, ask for explanations, not just code: “Explain why this fixes it.” That way you learn, and you can check the answer. Good prompting is really just clear technical communication, the same skill you need with people.
