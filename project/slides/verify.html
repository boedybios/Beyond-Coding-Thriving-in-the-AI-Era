02 · Working with AI

Four checks before you use AI output

1

Read

Can I explain every line?

Ask AI to explain any part you don’t get.

2

Run

Does it pass tests, including edge cases?

Try empty, huge, and invalid input.

3

Check

Is it secure and efficient?

Look for secrets, unsafe input, and slow loops.

4

Own

Would I defend it in a code review?

If not, keep working until you would.

AI makes generating code fast. Your review is what makes it correct.

(~2 min) Four quick checks that turn AI output into code you can trust. Read: go line by line. If something is unclear, ask the AI to explain it, or look it up. Run: don’t trust “it should work”. Test it, especially edge cases like empty input, very large input, and invalid input. Check: look for leaked secrets, unvalidated input, and slow nested loops. Linters and security scanners help. Own: imagine a senior engineer asks “why did you do it this way?” If you can’t answer, keep working on it. This takes minutes, and it saves hours of debugging later.
