Know where AI goes wrong

ProblemWhat it looks like
HallucinationInvents functions, packages, or facts that don’t exist
Outdated knowledgeSuggests old library versions or deprecated APIs
Missing contextDoesn’t know your system, your users, or your constraints
Security blind spotsHardcoded secrets, unsafe queries, missing input checks
OverconfidenceSounds just as sure when it is wrong

A confident, fluent answer can still be wrong.

(~2 min) Five ways AI goes wrong, so you know what to look for. Hallucination: it can invent a function, a package, or a reference that sounds real but doesn’t exist. Attackers even publish malicious packages under names that AI tools tend to invent, so check that a package is real and trusted before you install it. Outdated knowledge: models learn from data up to a point in time, so they may suggest old versions or deprecated APIs. Missing context: it only knows what you give it. Security blind spots: hardcoded passwords, SQL built by joining strings, no input validation. Overconfidence: the tone is the same whether it’s right or wrong, so tone is not evidence.
