02 · Working with AI

Five everyday ways AI can help you

Understand code

“Explain this function step by step.”

Explore ideas

“Suggest three designs, with pros and cons.”

Debug

“Here’s the error and the code. Likely causes?”

Write docs

“Draft a README: setup, usage, examples.”

Automate routine work

“Write unit tests for these edge cases.”

Treat AI like a fast, eager teammate: very helpful, and sometimes confidently wrong.

(~2.5 min) Five everyday uses, each with a prompt they can try tonight. Understand code: paste a function from an open-source project and ask for a step-by-step explanation. Great for reading unfamiliar codebases. Explore ideas: ask for several options with trade-offs, not one answer. You still choose. Debug: give the exact error message and the relevant code; ask for likely causes before asking for a fix. Write docs: AI is good at turning your notes into a clear README or code comments. Automate routine work: tests, sample data, repetitive refactors. The teammate image matters: helpful and fast, but you would still review a teammate’s work before using it.
