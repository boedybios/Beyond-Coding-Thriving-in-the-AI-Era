03 · Growing in the AI era

Your 30-day starter plan

Week 1

Explore

Ask AI to explain code you wrote before. Note where it’s wrong.

Week 2

Build

Start a small project for a real problem. Log what AI suggests and what you keep.

Week 3

Verify

Write tests. Ask AI for a bug and security review, then check its claims.

Week 4

Share

Publish it with a README of your decisions. Ask someone for feedback.

By day 30: one real project, a README that shows your thinking, and the habit of checking AI’s work.

(~1.5 min) Turn the talk into action with one month and four small steps. Week 1: explore. Use an AI assistant on code you already understand, so you can spot when it’s wrong. Week 2: build. Pick a small, real problem. Keep a simple log: what AI suggested, what you kept, and why. Week 3: verify. Write tests and ask AI to review for bugs and security issues, then check whether its findings are actually right. Week 4: share. Publish on GitHub with a README using the write-up template, and ask a friend, senior, or lecturer for feedback. Checkpoint: you should be at about minute 44.
